# 原生画板同步

SVG 是唯一的本地编辑源；JSON 只保存画板映射和同步基准。Mermaid 继续使用代码块，与本页原生画板链路分开。

## 本地文件

```text
文档.md
.assets/文档/
  画板-1.board.svg
  画板-1.board.json
```

Markdown 单独占行引用 `.board.svg`。本地首次绘制时无需 JSON，成功上传后自动生成；普通 `.svg` 不自动识别为画板。已有 JSON 必须与 SVG 配对保留，不通过删除元数据绕过冲突。

JSON 的 `schema_version: 2` 保存：

| 字段 | 用途 |
| --- | --- |
| preview_hash | 上次同步的本地 SVG 字节哈希 |
| baseline_hash | 与该本地副本对应的远端节点内容哈希 |
| bindings | 各目标文档的画板 token 和远端基准哈希 |
| origin_url | 拉取来源地址（可选） |

不保存完整 nodes，也不支持通过 JSON 编辑图形。节点只在调用飞书 CLI 时读取，用于内容哈希和回读校验；未修改的原生画板保留，不重新导入。

## 同步行为

| 情况 | 行为 |
| --- | --- |
| 首次上传或上传到新文档 | 创建画板，导入 SVG，校验节点，再导出最终 SVG 并写入 JSON |
| 两端均未修改 | 保留画板；必要时升级旧元数据 |
| 仅本地 SVG 修改 | 更新原 token，读回最终 SVG，刷新两侧基准 |
| 仅远端修改 | 保留远端，导出 SVG 更新本地及基准 |
| 两端都改且内容不同 | 报告冲突，不覆盖 |
| 本地存在未同步修改时拉取 | 拒绝覆盖 |
| 映射的远端画板不存在或存在未映射画板 | 报告冲突，不按位置猜测 |
| 同一画板重复引用 | 拒绝；需复制文件后分别引用 |

上传后本地 SVG 对应服务端导出的实际图形，可能与原始绘图代码不同。若要保留作者原稿，另存一份或使用版本管理。外部工具直接修改 nodes 后，应先 pull 再继续编辑。


多步远端操作不是事务。创建成功但后续导出或写文件失败时，错误会指出已知 token；先拉取到新路径核对并恢复映射，不直接重复创建。不保证 SVG 导入保留全部分组、连接绑定或特殊图元，不能仅凭文字回读成功就宣称视觉无损。

## 展示尺寸

首次创建通过官方 CLI 调用文档块创建接口，设置画板显示区域。优先读取 SVG viewBox 的宽高比例，其次读取 width/height；宽度按 820 px 计算，高度按比例限制在 90–1640 px。无法取得尺寸时采用 820 × 460。实际显示仍受文档页宽及屏幕高度限制。

画板内的图形尺寸和文档中的画板块尺寸不同。更新 nodes 不会同步调整块的宽高；原有横图换成长图后，旧高度可能导致内容缩小。现有公开块更新接口未提供画板宽高更新，本工具保留原 token 与块，不为调整尺寸自动删除重建。已有画板比例变化后需在飞书中调整显示区域，计划会提示这一限制。

接口依据：[画板块结构](https://open.feishu.cn/document/docs/docs/data-structure/block.md)、[创建块](https://open.feishu.cn/document/server-docs/docs/docs/docx-v1/document-block/create.md)、[更新块](https://open.feishu.cn/document/server-docs/docs/docs/docx-v1/document-block/patch.md)。

## 旧文件迁移

读取 schema 1 时先比较旧 nodes 与原基准：未修改才允许迁移；有未同步节点编辑就拒绝，避免丢弃工作。成功同步后写为 schema 2。旧 JPG/PNG 预览可供识别，编辑或上传到新文档前应先拉取为 SVG。旧素材不会自动删除。
