# 字体颜色

larkmd-sync 使用标准行内 HTML 表达字体颜色。上传时将 CSS `color` 转成飞书的 `text-color`；下载时从同一版本的完整 XML 恢复 Markdown 导出中省略的字体颜色。

## 1. 语法选择

实现前核对了以下现有协议与第三方扩展。

| 方案 | 示例 | 兼容性与取舍 |
| --- | --- | --- |
| CommonMark 行内 HTML | `<span style="color:#d83931">红字</span>` | 采用。无需额外定义括号语法；颜色显示取决于渲染器是否保留 CSS |
| Pandoc `bracketed_spans` | `[红字]{style="color:#d83931"}` | 语法已有标准化实践，但需要启用 Pandoc 扩展 |
| markdown-it-bracketed-spans + markdown-it-attrs | `[红字]{style="color:#d83931"}` | 可实现 Pandoc 风格，需要两个渲染插件；larkmd-sync 当前未引入该语法 |

依据：[CommonMark Raw HTML](https://spec.commonmark.org/0.31.2/#raw-html)、[Pandoc bracketed_spans](https://pandoc.org/MANUAL.html#extension-bracketed_spans)、[markdown-it-bracketed-spans](https://github.com/mb21/markdown-it-bracketed-spans)、[markdown-it-attrs](https://github.com/arve0/markdown-it-attrs)。CommonMark 允许 HTML，并不保证每个宿主都保留内联样式。

## 2. 使用方法

```markdown
普通文字，<span style="color:#d83931">需要关注的文字</span>。

5. <span style="color:#d83931">等待三板配置同步完成后再继续启动</span>

<span style="color:#245bdb">**加粗蓝字**和[链接](https://example.com)</span>
```

输入支持 `#RGB`、`#RRGGBB`、整数 `rgb(r,g,b)` 和常见基础 CSS 色名。仅处理字体颜色，不支持透明度、CSS 变量、背景色或任意 CSS 声明。代码块和行内代码中的 span 示例保持字面量。

### 2.1 飞书色板

飞书字体颜色使用固定色板。工具使用以下 RGB 映射。

| 颜色 | 精确 RGB |
| --- | --- |
| 红 | `#d83931` |
| 橙 | `#de7802` |
| 黄 | `#dc9b04` |
| 绿 | `#2ea121` |
| 蓝 | `#245bdb` |
| 紫 | `#6425d0` |
| 灰 | `#8f959e` |

建议使用表中的十六进制值。其他输入颜色按 RGB 欧氏距离映射到这七种颜色，并在推送计划中报告 `text_color_palette_normalized`。例如标准 CSS `red` 为 `#ff0000`，同步到飞书时映射为 `#d83931`。比较正文也使用映射后的值，避免仅因颜色记法不同反复出现差异。

### 2.2 保真边界

普通段落、标题和列表中的字体颜色按所属文本块恢复；加粗和链接可与颜色组合。无法唯一定位的重复文本块、无法识别的行内结构和不支持的颜色会产生阻断警告，禁止静默丢色后覆盖远端。

本功能不保证其他排版属性、任意 HTML/CSS、第三方 Markdown 扩展或所有复杂表格结构的无损往返。飞书可能重新拆分相邻的富文本片段，原始 Markdown 标签位置不一定相同。
